# pan-validation-project
Python-based PAN Number Validation project using Pandas for data cleaning, validation, duplicate detection, pattern checks, and Excel report generation.

# PAN Validation Project

**Overview**
This project validates PAN numbers using Python and Pandas.

**Features**
- PAN format validation
- Duplicate detection
- Sequential character checks
- Adjacent repetition checks
- Missing value analysis
- Excel report generation

**Technologies Used**
- Python
- Pandas
- OpenPyXL
- Jupyter Notebook

**Output**
The project generates a final Excel report containing:
1. PAN Validation Sheet
2. Summary Sheet
